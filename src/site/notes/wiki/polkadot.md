# Polkadot

**TL;DR:** Polkadot is the Layer-0 relay chain providing shared security to [[wiki/hydration\|hydration]] and other parachains. [[wiki/hydration\|hydration]] is the largest DeFi protocol in the Polkadot ecosystem by TVL.

## Relevance to Hydration

- **Shared security:** Hydration inherits security from Polkadot's validator set rather than maintaining its own
- **[[wiki/xcm\|xcm]]:** Cross-Consensus Messaging enables native interoperability between parachains — no external bridges needed within the ecosystem
- **[[wiki/opengov\|opengov]]:** Polkadot's governance framework is used by Hydration for on-chain governance
- **[[wiki/asset-hub\|asset-hub]]:** Polkadot's system chain for asset issuance; common landing zone for stablecoins
- **Substrate:** The Rust framework Hydration's runtime is built with

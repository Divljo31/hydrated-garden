# Asset Hub

**TL;DR:** Asset Hub is [[wiki/polkadot\|polkadot]]'s system chain for asset issuance and management. It serves as a common landing zone for stablecoins (USDT, USDC) and other cross-chain assets.

## Relevance to Hydration

[[wiki/hydration\|hydration]] uses [[wiki/xcm\|xcm]] to interact with Asset Hub for cross-chain asset transfers. Remote swaps can route through Asset Hub — e.g., DOT on the relay chain → USDT on Asset Hub in a single UX flow.

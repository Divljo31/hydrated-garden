# Snowbridge

**TL;DR:** Snowbridge is a trustless native bridge between [[wiki/polkadot\|polkadot]] and Ethereum with no additional trust assumptions. [[wiki/hydration\|hydration]] uses it alongside [[wiki/wormhole\|wormhole]] for extra-ecosystem connectivity, while [[wiki/xcm\|xcm]] handles Polkadot interoperability.

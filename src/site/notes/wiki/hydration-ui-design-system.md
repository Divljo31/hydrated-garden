# hydration-ui design system

**TL;DR:** `packages/ui/` — `@galacticcouncil/ui`. Radix primitives + Emotion CSS-in-JS on a Theme-UI theme object, tokens generated by style-dictionary from the remote `hydration-styles` repo. **76 component folders** as of Aug 2026 (six new since May: `Prose`, `PromoteBanner`, `OptionCard`, `PositionCard`, `EditableText`, `MorphLabel`). Storybook **10.3.5** with `@storybook/addon-mcp`. Only internal dep is [[wiki/hydration-ui-utils\|hydration-ui-utils]].

## Import surface — directory-level exports only

```json
// packages/ui/package.json
"exports": {
  "./*": "./src/*/index.ts",
  "./fonts.css": "./src/assets/fonts/fonts.css",
  "./assets/images/*": "./src/assets/images/*"
}
```

The wildcard maps to **top-level `src/` directories**, not to individual components. Valid specifiers are exactly:
`@galacticcouncil/ui/components`, `/theme`, `/styles`, `/utils`, `/hooks`, `/types`, `/jsx`, plus `/assets/icons` and `/assets/visuals`.
There is **no `@galacticcouncil/ui/button`** — everything comes off the `components` barrel (`src/components/index.ts`, `export * from "./<Name>"` for each folder).

```typescript
// consumer side
import { Button, Modal, DataTable } from "@galacticcouncil/ui/components"
import { getToken, createVariants } from "@galacticcouncil/ui/utils"
import { ThemeProvider, useTheme, mq } from "@galacticcouncil/ui/theme"
import { KrakenLogo } from "@galacticcouncil/ui/assets/icons"
```

## Theme

`src/theme/index.ts` builds a Theme-UI theme with `makeTheme()` from generated tokens:

```typescript
// packages/ui/src/theme/index.ts (excerpt)
export type ThemeProps = ThemeBaseProps & TokenProps
export type ThemeName = keyof typeof themes          // "light" | "dark"
export type ThemePreference = ThemeName | "system"
export type ThemeColor = Join<Paths<ThemeProps["colors"]>, ".">
export type ThemeToken = Join<Paths<ThemeProps>, ".">

export const themes = { light, dark }

declare module "@emotion/react" {
  export interface Theme extends ThemeProps {}
}
```

- `space` is derived from token paddings **plus auto-generated negative keys** (`-m`, `-l`, …).
- `zIndices`: `header: 5`, `modal: 10`, `popover: 1000`, `tooltip: 9999`.
- `sizes.content = pxToRem(1360)` — the app's max content width.
- The Emotion `Theme` interface is module-augmented, so `theme.colors.…` is fully typed in every styled component.

`src/theme/provider.tsx` exports `ThemeProvider` (children-only; no `theme` prop), `useTheme()` (returns `{ themeProps, getToken, theme, themePreference, setThemePreference }`), `useThemeUI()`, and a persisted `useThemeStore` zustand store holding `themePreference` (`"light" | "dark" | "system"`).

## `getToken` is an overloaded function

```typescript
// packages/ui/src/utils/index.ts
export function getToken(token: ThemeToken): (theme: ThemeUI) => ThemeUICSSObject
export function getToken(token: ThemeToken[]): (theme: ThemeUI) => ThemeUICSSObject[]
export function getToken(token: ThemeToken | ThemeToken[]) {
  return (theme: ThemeUI) =>
    Array.isArray(token) ? token.map((t) => get(theme, t)) : get(theme, token)
}
```

Passing an array now returns an array of resolved values (used for gradient stops / multi-color borders). Sibling helpers in the same file: `createStyles(cb)`, `createVariants<TKey>(cb)` (variant-map factory used by nearly every `.styled.ts`), `pxToRem`, `getSpacingValue`, `ROOT_FONT_SIZE = 16`, `UI_SCALE_VAR = "--ui-scale"`, plus re-exports of `css`, `styled` and `../styles/container`.

## Token pipeline

`yarn theme` → `style-dictionary/build.mjs`:
1. **Fetches** `tokens.json` from `github.com/galacticcouncil/hydration-styles` (branch `tertiary`) at build time — the token source is remote, not vendored.
2. Registers `@tokens-studio/sd-transforms` + a custom `custom/number/rem` transform (`px / 16` → `rem`).
3. `permutateThemes` → emits `src/theme/tokens/index.ts` (**generated — never hand-edit**).

## Styles / responsive

`src/styles/media.ts` exports `mq`, `BREAKPOINTS_VALUES`, `useBreakpoints`, `useResponsiveValue`, `useUiScale`. `theme/index.ts` re-exports only `mq`, `useBreakpoints`, `useResponsiveValue` and the `ScreenBreakpoint` / `ScreenType` types — `useUiScale` must be imported from `@galacticcouncil/ui/styles`. `src/styles/container.ts` adds container-query helpers, re-exported from `@/utils`. `src/styles/scale.ts` drives the `--ui-scale` CSS variable that `AccountAvatar` and other pixel-sized components multiply into their dimensions.

## Adding a component

1. `src/components/<Name>/` with `<Name>.tsx`, `<Name>.styled.ts` (use `createVariants` + `getToken`), `<Name>.stories.tsx`, `index.ts`.
2. Add `export * from "./<Name>"` to `src/components/index.ts` — otherwise it is unreachable from `@galacticcouncil/ui/components`.
3. New tokens must land in the upstream `hydration-styles` repo; re-run `yarn theme`.
